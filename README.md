# AdaptiveCloudFinalProject
# Adaptive Cloud Resource Allocation Using Machine Learning and Cost-Aware Workload Prediction

## 1. Project Description

This project uses Machine Learning to predict future cloud CPU and memory requirements and recommend suitable cloud resources.

It aims to reduce resource wastage, improve resource utilization and minimize estimated cloud costs.

## 2. Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Random Forest
- Extra Trees
- Isolation Forest

## 3. Main Features

- Cloud workload dataset generation
- CPU and memory usage prediction
- Anomaly detection
- Workload classification
- Adaptive CPU and memory allocation
- Cost-aware resource optimization
- Fixed, reactive and adaptive cost comparison
- SLA violation evaluation
- Next-hour workload prediction
- Graphical result visualization

## 4. Machine Learning Models

- Random Forest Regressor
- Extra Trees Regressor
- Isolation Forest

## 5. Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R2)
